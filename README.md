# Todo App

A modern and efficient task management application built with TypeScript, CSS, JavaScript, and HTML. This Todo App helps you organize tasks, increase productivity, and keep track of your daily goals through a clean and responsive user interface.

## Features

- **Add, Edit, Delete Tasks:** Easily create, update, and remove your todos.
- **Mark as Complete:** Clearly visualize which tasks are finished and which are pending.
- **Categorize & Filter Tasks:** Group tasks by category, due date, and completion status.
- **Responsive UI:** Works seamlessly across desktops, tablets, and mobile devices.
- **Persistent Storage:** Your todos are stored locally, so you never lose progress.

## Technology Stack

- **TypeScript** (73.6%): Business logic and robust typing.
- **CSS** (17.1%): Layout and styling for a beautiful experience.
- **JavaScript** (5.8%): Interactive UI features.
- **HTML** (3.5%): Markup and structure.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18+ recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/abyss1234/todo_app.git
   cd todo_app
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Run the application**
   ```bash
   npm start
   # or
   yarn start
   ```

### Build for Production

```bash
npm run build
# or
yarn build
```

Output will be available in the `dist` or `build` folder.

## Usage

After launching the development server, visit [http://localhost:3000](http://localhost:3000) in your browser. Start adding tasks, organize your day, and check off completed todos!
